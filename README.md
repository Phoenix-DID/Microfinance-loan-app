Meridian Microfinance is a corporate loan servicing and portfolio operations web application designed for microfinance institutions. Authenticated officers can verify sessions with Google Sign-In alongside WebAuthn-backed Face ID and fingerprint passkeys, lock and unlock their desk biometrically, originate and underwrite commercial micro-loans with live amortization previews, manage loan portfolios, and track recent transactions and pending payment deadlines in a real-time Firestore-backed list view.
